## The line

> I didn't miss that spot — my cliff sensor saw the rug fringe, screamed 'stairs,' and I reversed before I fell to my death.

## How it works

`main.py` (Python stdlib only) writes exactly that one line — no trailing
newline, 122 characters — to `/output/entry.txt` and sets the file mode to
0644.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
